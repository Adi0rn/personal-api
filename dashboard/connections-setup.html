Connections

Google Calendar & Gmail

  1. Open Google Cloud Console and create a project named PAPI.
  2. In APIs & Services → Library, enable Google Calendar API and Gmail API.
  3. Open Google Auth Platform. Set the app name to PAPI, choose your support/contact email, and choose External if using a personal Google account. Under Audience, keep the app in Testing and add your Google email as a test user.
  4. Under Data Access, add these read-only scopes:
    https://www.googleapis.com/auth/calendar.events.readonly
    https://www.googleapis.com/auth/gmail.readonly
  5. Under Clients, create an OAuth client of type Web application. Add this exact authorized redirect URI:
    http://127.0.0.1:8000/connections/google/callback
  6. Copy the client ID and client secret into the local form below, save, then sign in to Google. Approve both Calendar and Gmail permissions.
Sign in / reconnect Google ↗

Credentials stay encrypted on this computer. Do not paste them into chat or commit them. Google may restrict unverified apps or require authorization again; any Google warning or account approval remains yours to review.

GitHub

  1. Open GitHub → Fine-grained personal access tokens.
  2. Name it PAPI, choose an expiration date and your account as resource owner, then choose Only select repositories and select the repositories you want PAPI to list.
  3. Leave account permissions and optional repository permissions unset. Metadata: Read-only is included automatically. No code write permission is needed.
  4. Generate the token and paste it below. It should start with github_pat_. Renew it here when it expires.

PAPI reads repository metadata and public activity. It does not push code, change issues, or publish anything.
